# Privacy policy

Last updated: November 17, 2026

AWL Agent Workspace is a personal tool with a single user, its owner, Adam Lester. It is not offered to anyone else.

## What it accesses

When the owner signs in with Google, the tool can read Gmail messages, Google Drive files, Google Sheets and Google Calendar events in the owner's own Google account (awl.autohub@gmail.com), and can edit Google Docs in that account.

## How the information is used

The information is processed only on the owner's own computer, to let the owner's software assistants find and read the owner's own content and edit the owner's own documents. It is not sent to any server run by this project, and this project runs no servers.

## Sharing and storage

The information is not sold, shared with third parties, used for advertising, or used to train models. Sign-in tokens are stored encrypted on the owner's computer. Content that an assistant reads may be processed by the AI service the owner chooses to run that assistant with, only to carry out the owner's request.

## Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Retention and removal

Tokens remain until the owner revokes them at https://myaccount.google.com/permissions or deletes the local files. Revoking access ends all use immediately.
