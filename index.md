# AWL Autohub

AWL Autohub is a personal project by Adam Lester. It is the public home for small automation tools that run on one person's own computer and connect only to that person's own accounts. It is not a product and it is not offered to the public.

## Tools

AWL Agent Workspace: lets the owner's own software assistants read email, Google Drive files, Google Sheets and Google Calendar in a single Google account (awl.autohub@gmail.com), and edit Google Docs in that account. It has one user, the owner.
